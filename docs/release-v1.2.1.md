## 화면을 더 간결하게 정리했습니다

- 상단 모델·사용량은 두 개의 작은 요약 카드로 표시하고, 누르면 상세 수치를 펼칩니다.
- 눈에 잘 보이는 **↻ 새로고침** 버튼을 추가했습니다. 확인 중 표시와 완료 시각을 보여주며 중복 요청을 막습니다. Claude는 마지막 수신 정보를 다시 읽습니다.
- 카드 크기·테마·펫·알림·에이전트 연결은 **설정** 메뉴에 모았습니다.
- 여백·글자 크기·대비를 정리하고, 물 배경과 테두리 색을 옅게 조정했습니다. 라이트·다크 테마와 메모장 모드를 유지합니다.

**Tidewatch-Setup.exe**를 받아 앱을 종료한 뒤 설치하세요. Windows x64용이며 현재 빌드는 미서명 파일입니다. 에이전트 상태 갱신에는 Node.js가 필요하고 자동 업데이트는 없습니다. 기존 세션과 사용량 연결 설정은 유지합니다.
