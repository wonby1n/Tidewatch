## 메모 모드에서 상태와 진행 상황을 더 쉽게 확인하세요

- **너 차례·막힘·진행 중·완료**를 진한 배지와 기호로 구분합니다. 상단 집계에도 상태 이름을 표시합니다.
- 진행 막대에 더해 **완료 단계 수와 %**를 함께 표시합니다. 단계 정보가 없으면 진행률을 추측하지 않고 미확인으로 표시합니다.
- **너 차례:** 사용자가 해야 할 일을 먼저 보여줍니다.
- **막힘:** 오류 요약, 파일 위치, 막힌 단계를 표시합니다.
- **완료:** 완료 결과와 100%를 표시합니다.
- 작업 제목과 설명은 최대 두 줄까지 표시하며, 30분 넘게 갱신되지 않은 작업은 따로 안내합니다.
- 메모 항목은 마우스 또는 키보드 Enter·Space로 큰 현황판을 열 수 있습니다.

라이트·다크 메모 화면과 네 상태, 진행률 미확인, 오류 위치, 가로 넘침을 검사했습니다.

**Tidewatch-Setup.exe**를 받아 앱을 종료한 뒤 설치하세요. Windows x64용 미서명 빌드입니다. 에이전트 갱신에는 Node.js가 필요하며 자동 업데이트는 없습니다. 기존 세션은 유지합니다.
