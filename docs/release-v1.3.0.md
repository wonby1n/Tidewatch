## 여러 세션의 완료·응답 요청을 더 쉽게 확인하세요

- 물음표 대신 **답장 모양 응답 배지**를 사용합니다.
- 작업이 완료·응답 필요·막힘 상태로 바뀌면 **결과 한 줄을 담은 OS 알림**을 보내고, 앱 안에도 최근 소식을 표시합니다.
- 같은 상태를 반복 갱신하거나 앱을 다시 시작할 때 이전 완료 알림을 중복 발송하지 않습니다.
- Claude 카드와 알림에서 **Claude 앱 열기**, 카드별 **대화 링크 연결**을 지원합니다. 링크가 없으면 정확한 세션은 자동 선택하지 않습니다. Code 링크의 세션 직접 이동은 앱 환경에 따라 확인이 필요합니다.
- 터미널 세션은 다른 앱에서 재개하지 않고 Tidewatch의 작업 카드로 돌아갑니다. 원본 터미널 탭 선택은 아직 지원하지 않습니다.
- 펫 창이 준비됐는지 확인하고, 오류·시간 초과 시 버튼을 복구합니다. 시작 오류는 로컬 `pet-error.log`에 기록합니다.

**Tidewatch-Setup.exe**를 받아 앱을 종료한 뒤 설치하세요. Windows x64용 미서명 빌드이며 에이전트 갱신에는 Node.js가 필요합니다. 자동 업데이트는 없습니다. 기존 세션과 설정은 유지합니다.

알림은 Tidewatch 스킬이 상태를 기록하는 세션 기준입니다. 임의의 터미널 명령을 자동 감시하지는 않습니다. OS 알림 팝업 표시는 Windows 알림·방해 금지 설정의 영향을 받습니다.

# 프로젝트에서 터미널 시작·이어하기

앱 위쪽 `터미널 작업`에서 Claude Code·Codex의 새 작업 또는 대화 이어하기를 선택할 수 있습니다. 프로젝트 폴더를 고르면 그 위치에서 CLI가 열려 `cd`를 직접 입력할 필요가 없습니다. 마지막 사용 폴더를 기억합니다.

이어하기는 CLI의 대화 선택 목록을 엽니다. 카드와 특정 원본 대화의 자동 연결, 실행 중인 터미널 포커스 이동은 아직 지원하지 않습니다. 이미 실행 중인 대화는 기존 창에서 계속 사용하세요. 해당 CLI가 설치되어 있어야 하며, Tidewatch가 대신 프롬프트를 전송하지 않습니다.
