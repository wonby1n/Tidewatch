# Tidewatch v1.4.0

GitHub 계정의 저장소 목록에서 프로젝트를 한 번 등록하고, 다음부터 폴더 선택 없이 Claude Code·Codex 새 작업과 이어하기를 시작할 수 있습니다.

- 공식 GitHub CLI 브라우저 인증과 앱 안의 일회용 코드 표시
- 비공개 저장소 구분, 저장소 검색과 목록 더 불러오기
- 기존 로컬 폴더 연결 시 Git origin 검증 또는 선택한 저장소 받기
- 등록된 프로젝트에서 에이전트 선택 후 새 작업·이어하기
- 연결 해제와 프로젝트 등록 해제 시 작업 폴더 유지

GitHub CLI 인증 화면과 기본 권한(repo·read:org·gist)을 안내합니다. Git과 AI CLI는 별도 설치가 필요합니다. 이어하기는 CLI 대화 선택 목록을 열며 특정 대화 자동 연결은 아직 지원하지 않습니다.

Windows x64, 코드 서명 없는 개인 배포 빌드입니다. SHA256SUMS.txt로 설치 파일을 확인하세요. [상세 안내](https://github.com/wonby1n/Tidewatch/blob/main/docs/github-projects.md)
