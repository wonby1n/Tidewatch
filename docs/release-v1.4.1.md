# Tidewatch v1.4.1

알림이 표시되지 않을 때 앱 안에서 직접 확인할 수 있도록 개선했습니다.

- 설정에 실제 Windows `알림 테스트` 버튼 추가
- 요청·Windows 전달 완료·전달 실패·미확인 상태와 마지막 시각 표시
- 알림 실패를 조용히 무시하지 않고 로컬 진단 파일에 기록
- Windows 초기화 전에 Tidewatch 앱 ID 설정, 설치된 바로가기의 알림 활성화 ID 사용

Windows 전달 완료는 실제 팝업 확인과 다릅니다. 앱의 과거 상태는 시작 시 다시 알리지 않으며, 동일 상태 반복 갱신도 중복 발송하지 않습니다. Windows 알림 설정은 자동으로 변경하지 않습니다.

Windows x64용 코드 서명 없는 빌드입니다. SHA256SUMS.txt로 설치 파일을 확인할 수 있습니다.
